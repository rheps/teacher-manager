Teacher Manager includes the Microsoft Edge WebView2 Evergreen Bootstrapper so
the installer can prepare the screen-rendering Runtime when needed.

Official download page: https://developer.microsoft.com/en-us/microsoft-edge/webview2/
Distribution information: https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution
Official terms source: https://developer.microsoft.com/microsoft-edge/api/eula/webview2?locale=en-us
Exact official terms JSON: licenses/webview2-evergreen-terms-en-us.json

The installer shows the full terms and requires explicit acceptance before it
can run the Bootstrapper.  The Runtime includes Microsoft Defender SmartScreen,
which can send end-user information to Microsoft as described at:
https://aka.ms/privacy
https://learn.microsoft.com/en-us/microsoft-edge/privacy-whitepaper#smartscreen

Microsoft does not sponsor or endorse Teacher Manager.

Teacher Manager includes the certifi root certificate list 2026.02.25 (the
Mozilla CA bundle as certifi/cacert.pem) so its own downloads from GitHub verify
on a freshly installed Windows whose root store has not yet fetched newer roots.

Source: https://github.com/certifi/python-certifi
License: MPL-2.0 (https://www.mozilla.org/MPL/2.0/).  The bundle carries no
private keys and is used only to verify servers.
