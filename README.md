# Teacher Manager

**경기도 선생님을 위한 구글 업무 자동화 프로그램**

교육청 업무 메신저(Brity)에 온 쪽지·공지를 단축키 한 번으로 Google 캘린더·할 일에 자동 정리하고,
출결 Google Sheet에 적기만 하면 결석 신고서 작성과 학생·학급 안내 문자까지 자동으로 이어 줍니다.

- 만든 사람: **Big-Silver EDU LAB** (부천 중원고등학교 교사 김대은) · https://big-silver.xyz

---

## 내려받기

**[⬇ 최신 설치 파일 받기 (TeacherManager-Setup)](https://github.com/rheps/teacher-manager/releases/latest)**

위 링크에서 `TeacherManager-Setup-<버전>.exe` 파일 하나만 받으면 됩니다.

## 설치 순서

1. 받은 `TeacherManager-Setup-<버전>.exe`를 더블클릭합니다.
2. **파란 경고 창이 뜨면** (아래 "파란 경고가 떠요" 참고):
   - **"추가 정보"** 를 클릭하고
   - **"실행"** 버튼을 클릭합니다.
3. 한국어 설치 화면이 뜨면 **"다음"** 을 눌러 진행합니다. 관리자 권한은 필요 없습니다.
4. 설치가 끝나면 **"지금 Teacher Manager 실행"** 에 체크된 상태로 "완료"를 누릅니다.
5. 프로그램이 열리면 처음 설정 화면이 순서대로 안내합니다 — 화면을 따라가기만 하면 됩니다.

## 파란 경고가 떠요 (정상입니다)

Windows는 아직 서명 절차를 거치지 않은 새 프로그램을 실행할 때
"Windows의 PC 보호" 라는 파란 경고를 보여줍니다.
이 프로그램은 교사 개인이 만들어 무료로 배포하는 것이라 유료 서명 절차를 거치지 않았을 뿐,
경고 창에서 **추가 정보 → 실행** 두 번만 누르면 정상적으로 설치됩니다.

## 필요한 것

- Windows 10 또는 11
- **교육디지털원패스 및 경기도교육청 클라우드서비스에 가입한 계정(@goedu.kr)** — 프로그램 안 설정 화면에서 이 계정으로 구글 로그인을 합니다
- 인터넷 연결 (설치 중 구글 연결 도구를 자동으로 준비합니다)

## 업데이트

새 버전이 나오면 프로그램 홈 화면 맨 위에 **"새 버전 받기"** 안내가 자동으로 뜹니다.
누르면 이 페이지로 와서 새 설치 파일을 받아 실행하면 되고, 기존 설정은 그대로 유지됩니다.
