# Teacher Manager

**경기도 선생님을 위한 구글 업무 자동화 프로그램**

교육청 업무 메신저(Brity)에 온 쪽지·공지를 단축키 한 번으로 Google 캘린더·할 일에 자동 정리하고,
출결 Google Sheet에 적기만 하면 결석 신고서 작성과 학생·학급 안내 문자까지 자동으로 이어 줍니다.

- 만든 사람: **Big-Silver EDU LAB** (부천 중원고등학교 교사 김대은) · https://big-silver.xyz

---

## 내려받기 — 두 가지 중 하나를 고르세요

**[⬇ 내려받기 페이지 열기 (최신판)](https://github.com/rheps/teacher-manager/releases/latest)**

| | 파일 | 이런 분께 |
|---|---|---|
| **① 설치판 (기본 추천)** | `TeacherManager-Setup-<버전>.exe` | 대부분의 선생님. 설치 몇 번 클릭이면 끝나고, 따로 준비할 게 없어요. |
| **② 미설치판** | `TeacherManager-Portable-<버전>.zip` | 설치판이 차단되거나 설치가 부담스러운 분. 압축 풀고 "시작하기" 더블클릭이면 돼요. |

## ① 설치판 — 설치 순서

1. 받은 `TeacherManager-Setup-<버전>.exe`를 더블클릭합니다.
2. **파란 경고 창이 뜨면** (아래 "파란 경고가 떠요" 참고):
   - **"추가 정보"** 를 클릭하고
   - **"실행"** 버튼을 클릭합니다.
3. 한국어 설치 화면이 뜨면 **"다음"** 을 눌러 진행합니다. 관리자 권한은 필요 없습니다.
4. 설치가 끝나면 **"지금 Teacher Manager 실행"** 에 체크된 상태로 "완료"를 누릅니다.
5. 프로그램이 열리면 처음 설정 화면이 순서대로 안내합니다 — 화면을 따라가기만 하면 됩니다.

## ② 미설치판 — 사용 순서

1. 받은 `TeacherManager-Portable-<버전>.zip`을 원하는 곳(예: 문서 폴더)에 **전부 풀어 주세요.**
2. 풀린 `TeacherManager` 폴더 안의 **"시작하기.vbs"** 를 더블클릭합니다.
   (컴퓨터 설정에 따라 그냥 "시작하기"로 보일 수 있어요)
3. 첫 실행은 준비 작업(파이썬 등 자동 설치) 때문에 **몇 분 걸려요** — 인터넷이 필요합니다.
   두 번째부터는 바로 열리고, 바탕화면에 바로가기도 자동으로 생깁니다.
4. 실행해도 아무 일이 없으면 같은 폴더의 **"시작이 안될 때"** (검은 창)를 대신 더블클릭해 보세요 —
   같은 준비를 해 주면서 진행 상황을 화면에 보여줍니다.

## 파란 경고가 떠요 (정상입니다)

Windows는 아직 서명 절차를 거치지 않은 새 프로그램을 실행할 때
"Windows의 PC 보호" 라는 파란 경고를 보여줍니다.
이 프로그램은 교사 개인이 만들어 무료로 배포하는 것이라 유료 서명 절차를 거치지 않았을 뿐,
경고 창에서 **추가 정보 → 실행** 두 번만 누르면 정상적으로 설치됩니다.

## "스마트 앱 컨트롤이 차단했습니다"라고 떠요

프로그램에 문제가 있어서가 아니에요. **최근에 산 새 Windows 11 컴퓨터에만 기본으로 켜져 있는
"스마트 앱 컨트롤"** 기능이, 서명 절차를 거치지 않은 프로그램을 내용과 관계없이 일괄 차단하는 것입니다.
(학교 컴퓨터나 쓰던 컴퓨터에는 보통 이 기능이 없어서 이 화면도 안 뜹니다.)

이 기능이 켜진 컴퓨터에서는 설치판·미설치판 **모두 실행이 막히기 때문에**,
이 컴퓨터에서 쓰려면 기능을 꺼야 합니다:

1. **시작 → 설정** 을 엽니다
2. **개인 정보 및 보안 → Windows 보안** 으로 들어갑니다
3. **앱 및 브라우저 컨트롤** 을 클릭합니다
4. **스마트 앱 컨트롤 설정** 을 클릭합니다
5. **끄기** 를 선택합니다 → 이제 설치 파일을 다시 실행하면 됩니다 (파란 경고는 [추가 정보 → 실행])

읽고 결정해 주세요:
- ⚠️ **한 번 끄면 윈도우를 새로 설치하기 전까지 다시 켤 수 없습니다.** 본인 컴퓨터에 대한 결정입니다.
- 다만 꺼도 무방비가 되는 건 아닙니다 — Windows의 기본 보호(SmartScreen·Defender 백신)는 그대로 동작해요.
- 끄고 싶지 않다면 **학교 컴퓨터에서 사용**하는 방법도 있습니다 — 학교 PC에는 보통 이 차단이 없어요.

## 필요한 것

- Windows 10 또는 11
- **교육디지털원패스 및 경기도교육청 클라우드서비스에 가입한 계정(@goedu.kr)** — 프로그램 안 설정 화면에서 이 계정으로 구글 로그인을 합니다
- 인터넷 연결 (설치 중 구글 연결 도구를 자동으로 준비합니다)

## 업데이트

새 버전이 나오면 프로그램 홈 화면 맨 위에 **"새 버전 받기"** 안내가 자동으로 뜹니다.
누르면 이 페이지로 와서 새 파일을 받아 실행하면 되고, 기존 설정은 그대로 유지됩니다.
